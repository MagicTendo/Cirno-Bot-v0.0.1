## 🛠️ Features

It doesn't work very well now because it's very outdated and I didn't even finish it. The bot should list all of its features with the `>help` command. The bot's main characteristic is its economic system with multiple currencies: Cirno Coins, Arcade Coins, Card Coins and Lunatic Coins. Each type of coin is supposed to be used in only one shop to buy specific items. There's also two games that aren't finished, Card Battle, in which you have to buy cards to make a strong deck in order to defeat your opponent, and Mining Simulator, which is exactly what it sounds like. Wait, this looks a bit like [Tokinotsuki](https://github.com/MagicTendo/Tokinotsuki), doesn't it?
